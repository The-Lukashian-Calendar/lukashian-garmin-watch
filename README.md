This is a Watch Face for Garmin smartwatches. It displays the current time, day and year of the Lukashian Calendar.

Users can choose either the Earth or Mars instance via the Watch Face settings. Please allow up to 5 minutes for the
Watch Face to update after changing this setting.

To download it onto your Garmin smartwatch, please visit the [Garmin App page](https://apps.garmin.com/apps/60848d83-5c25-4a6b-a5de-2f5cb6d45bdb).

For more information on the calendar mechanism itself, please visit [lukashian.org](https://www.lukashian.org).
